# Mira Studio Jewels Operations CRM

## Overview

Mira Studio Jewels Operations CRM is an internal business management platform designed specifically for a custom jewelry manufacturing company.

The goal is to replace spreadsheets, WhatsApp conversations, and scattered documents with a single centralized platform.

The application should prioritize speed, simplicity, maintainability, and scalability.

# Coding Standards

- Use TypeScript everywhere.
- Never duplicate code.
- Keep components reusable.
- Keep business logic separated from UI.
- Use feature-based folder structure.
- Prefer Server Components where appropriate.
- Use mock data before connecting Supabase.
